PUBLICAÇÃO DO SITE TEMPOS PERTURBADOS

O site completo deve ser publicado pelo script localizado na pasta acima do
repositório:

  python publicar_site_github.py

O publicador executa, nesta ordem:

1. Atualiza o clone local com o GitHub.
2. Sincroniza as sessões e missões do Obsidian.
3. Valida o índice, os arquivos referenciados e o conteúdo das missões.
4. Mostra todos os arquivos alterados no site.
5. Pede confirmação antes de preparar o commit.
6. Solicita a mensagem do commit, oferecendo uma mensagem padrão.
7. Cria o commit e envia todas as alterações confirmadas ao GitHub.

Para apenas recriar conteudo/ sem commit ou push, use:

  python sincronizar_conteudo.py

O nome antigo continua funcionando como atalho para a publicação completa:

  python publicar_diario_github.py

IMPORTANTE

- Revise a lista mostrada antes de confirmar a publicação.
- Responder "não" preserva os arquivos locais sem criar commit.
- O sincronizador isolado nunca cria commit nem envia alterações.
