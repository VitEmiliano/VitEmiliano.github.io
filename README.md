# Amigo secreto

O site em [GitHub Pages](https://vitemiliano.github.io/) recebe a seleção de um dos 15 participantes e confirma o sorteio ou a consulta do resultado. Taiane e Vítor entram com a senha administrativa e escolhem entre os nomes disponíveis.

O endereço da API fica em `amigo-secreto.js`. O serviço guarda os resultados em um CSV privado com as colunas `participante` e `amigo sorteado`. A senha é configurada no serviço.
